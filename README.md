ziyno addons 

Features:
 - lever hitbox highlight
 - dynamic terminal hitbox highlight
 - lb timer for py
 - blood camp tracker
 - no hand sway
 - sword blocking
 - prevent placing player heads
 - fast visual sneak

Commands:
- /leverhitbox toggle to enable/disable lever highlighting
- /terminalhighlight to enable/disable terminal highlighting
- /nohandsway toggle to enable/disable nohandsway
- /lbtimer <seconds> to configure the lb timer, /lbtimer 0 to disable it
- /camps to show the average and median blood camps in a sesion, /allcamps to list out all camps (both are measured in tick time)

## Requirements

- Minecraft Java Edition 26.1.2
- Java 25
- Fabric Loader 0.19.3 or newer
- Fabric API 0.154.2+26.1.2
